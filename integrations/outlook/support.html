ReplyBrief for Outlook

This page is served by the ReplyBrief desktop app on this computer. If it loads, ReplyBrief is running and serving the add-in.

Getting started

  1. Open a message in Outlook and choose ReplyBrief on the Message tab.
  2. Paste the pairing code ReplyBrief shows on the desktop app.
  3. Press Capture conversation. Nothing is captured until you do.

Common problems

  • The task pane is blank. Outlook requires HTTPS. Trust the development certificate with dotnet dev-certs https --trust, then close and reopen the pane.
  • Nothing appears on the Message tab. The add-in may not be sideloaded for this mailbox, or your organisation blocks custom add-ins. Sideload from https://aka.ms/olksideload via My add-ins → Add a custom add-in → Add from File.
  • "The pairing code is missing or no longer current." The code changes every time ReplyBrief starts. Copy the current one.
  • "ReplyBrief could not be reached." The desktop app is not running, or the pairing code belongs to an earlier run.
  • "ReplyBrief is busy." Several captures are waiting for the desktop app to catch up. Wait a moment and capture again.

What gets captured

One message: its subject, its sender and its plain-text body. Thread history, attachments, inline images and linked files are not included, and messages longer than 60,000 characters are refused rather than truncated.

ReplyBrief captures only when you ask it to, and the add-in never contacts an AI service.
